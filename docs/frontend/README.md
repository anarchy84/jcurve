> 이 폴더(`docs/frontend/`)는 **프론트 디자인·콘텐츠 기획서**다. 코딩은 클로드코드가 한다.
> 담당 분리: **PLAN.md=아키텍처/DB/SEO · design-system.md=디자인토큰 · 이 폴더=화면 레이아웃+카피+미디어.**
> 아래 순서와 규칙대로 읽고 구현한다.

## 📖 읽는 순서 (반드시 이 순서)

```
1. 00_마스터_UX.md        ← 공통 규칙 먼저 (내비·푸터·타일리듬·아키타입·아나키규칙)
2. 08_역동성_레이어.md     ← ★톤 결정 ("애플 뼈대+버즈빌 생기"). 미디어·아이콘의 최종 기준

4. 07_힉스필드_미디어.md    ← 미디어 슬롯 참고 (단, 아이콘은 08이 우선 ↓)
```

## ⚠️ 충돌 해소 규칙 (헷갈리기 쉬운 3가지)

### 1. 아이콘: **08 > 07**
- 07의 "평면 추상 아이콘" 지시는 **무시.** 아이콘은 전부 **08의 3D 세트**(`public/media/icons3d/*.png`) 사용.
- 07은 **배경/타일 무드용 이미지**에만 유효(히어로 글로우 등).

### 2. 홈: **01 + 08 하이브리드**
- 01_홈.md의 섹션 구조·카피는 그대로.
- 그 위에 08의 역동 레이어(3D 아이콘·글래스 bento·orb·캐러셀·마퀴) 적용.
- 경계: **"크롬은 애플(design-system 유지), 콘텐츠는 버즈빌(08 역동)".**

### 3. 미디어: **있는 것만 쓰고, 없는 건 폴백**
현재 생성 완료된 에셋:
```
public/media/icons3d/  performance · seo · cpa · reward · wordpress · rankfree · leadbay · call2sale (8개)
public/media/bg/       hero-glow.png (히어로 배경 무드)
```
아직 없는 것(참조 시 깨짐 방지):
```
❌ icons3d/boostingshop · stat-adspend · stat-db · stat-campaign (4개, 다음 배치)
❌ hero.mp4 (히어로 영상, 다음 배치)
```
→ 없는 아이콘 자리는 **CSS 도형 폴백 또는 빈 자리 유지**(placeholder 이미지 만들지 말 것). 생성되면 교체.

## 🚦 구현 전 반드시 지킬 것

### [검증] 태그 = 대웅 확인 전까지 확정 금지
각 문서의 `{{-- [검증 V?] --}}` / `[검증]` / `[자료 필요]` 주석은 **그대로 blade 주석으로 남긴다.**
임의로 확정 카피를 박지 않는다. 전체 목록은 `06_문의.md` 맨 아래 인계표 참조.

**특히 위험 (절대 임의 생성 금지):**
- **CPA 금융계열**(주식·보험·코인·부동산 DB) 하위 랜딩 카피 → **법무 확인 전 히어로+CTA만**
- **랭크프리** "순위는 자체 추정치, 네이버 공식 아님" 고지 → **반드시 노출**
- **개인정보 수집 동의** 체크박스(`/contact`) → **필수. 빠지면 법 위반**
- 로고월 "함께한 브랜드" → "캠페인이 집행된 브랜드"로(직접계약 확인 전)

## ✅ 권장 구현 순서 (클로드코드)
```
1) 라우트 신설 + 내비/푸터(00) → 2) 홈(01+08) → 3) 서비스(02) → 4) 솔루션(03)
```
