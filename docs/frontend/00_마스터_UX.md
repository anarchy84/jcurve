> 작성 2026-08-04 · 담당: 기획·콘텐츠(Cowork) / 구현: 클로드코드
> **이 문서의 위치**: `PLAN.md`(뼈대)와 `design-system.md`(토큰) 사이의 빈칸 —
> "각 페이지가 화면에서 어떻게 생겼고, 무슨 글자가 들어가는가"를 채운다.
> 코드는 클로드코드가 짠다. 이 문서는 그 설계도다.

## 0. 이 문서를 읽는 법 (클로드코드용)

- 컬러·타이포·간격·버튼은 **전부 `design-system.md` 토큰만** 쓴다. 이 문서는 값을 새로 만들지 않는다.
- 각 섹션에 `[타일: 라이트|파치먼트|다크]`를 명시한다 → 그 색이 곧 섹션 구분선이다(디자인시스템 핵심).
- 카피는 **완성형**이다. `{여기 채우기}` 같은 플레이스홀더는 없다. 그대로 박으면 된다.
- 숫자·회사정보는 `CONTENT.md` 확정값과 일치한다. 임의로 바꾸지 않는다.

## 1. 사이트 한 문장 (모든 카피의 기준점)

> **"숫자로 증명하는 종합 퍼포먼스 마케팅 에이전시."**

- 톤: 과장 없는 자신감. 감탄사·물음표 훅("단 10초면!") 금지 — 그건 구버전 SEO숍 톤이다. 신규는 **에디토리얼(조용한 권위)**.
- 근거 우선: 형용사보다 숫자. "최고의"가 아니라 "373억 집행".
- 문장은 짧게. 한 섹션 헤드라인은 한 줄.

### 브랜드 메시지 위계 (위에서 아래로 신뢰를 쌓는다)
```
1. 우리가 누구인가   — 종합 퍼포먼스 마케팅 에이전시
2. 증거              — 373억 집행 · 15,700 캠페인 · 넷플릭스/LGU+/현대해상
3. 무엇을 하는가     — 9개 사업영역 (퍼포먼스·CPA·리워드·SEO·워드프레스 + 자체솔루션)
4. 왜 다른가         — 자체 데이터 솔루션(랭크프리) 보유 + SEO/AEO/GEO 실증
5. 행동              — 프로젝트 문의
```

## 2. 글로벌 내비게이션 (전 페이지 공통)

design-system.md: 검정(--black) 배경, 높이 44px, nav-link 12px, 834px↓ 햄버거.

### 구조 (드롭다운 = 파치먼트 프로스티드)
```
[제이커브인터렉티브]                          서비스  솔루션  성과  인사이트  회사   [문의하기]
                                                │       │              │
     ┌──────────────────────────────┘       │              └── 회사소개 / 아나키
     서비스 ▾                                  솔루션 ▾
     · 퍼포먼스 마케팅                          · 랭크프리 (데이터 솔루션)
     · CPA 마케팅                               · 부스팅샵 (셀프 마케팅)
     · 리워드 네트워크
     · SEO · AEO · GEO
     · 워드프레스 대행
```

- **좌측 브랜드**: 로고 이미지 없으면 워드마크 "제이커브인터렉티브" (15px/600).
- **우측 CTA**: `문의하기` — 파란 pill(--primary), 상시 노출. 이게 홈 히어로 CTA와 동일 목적지(`route('contact')`).
- **커뮤니티/로그인**: PLAN상 회원영역은 noindex. 내비 우측 끝에 `커뮤니티` + 로그인 상태별 `로그인|마이페이지`. 마케팅 방문자 흐름을 방해하지 않게 시각 비중은 최소(계정영역 12px).
- **모바일(834px↓)**: 햄버거 → 풀스크린 시트. 대분류 5개 → 탭하면 하위 펼침(아코디언). CTA는 시트 하단 고정.

## 3. 타일 교차 리듬 (이 사이트의 심장)

design-system.md: "풀블리드 타일이 라이트↔다크 교차, 색 전환이 섹션 구분선. gap 0."

### 리듬 규칙
1. **같은 색 타일 2개를 연속으로 두지 않는다.** 라이트 다음은 파치먼트나 다크.
2. **다크 타일은 리듬의 강세**다. 남발 금지 — 페이지당 1~2개. 히어로(검정)와 최종 CTA(다크)가 기본 앵커.
3. **파치먼트**는 라이트의 "숨 고르기". 신뢰 스트립·통계·푸터처럼 조용한 구간에.
4. **미디어(이미지·영상)는 유일한 그림자**(--shadow-media)를 가진다. 카드·버튼엔 그림자 금지.

### 표준 타일 내부 스택 (중앙 정렬)
```
[아이라벨/뱃지 (선택)]        ← tagline 21/600, --primary 또는 --primary-on-dark
헤드라인                      ← display-lg 40/600
서브카피 (1~2줄)              ← lead 28/400, muted
[CTA 1개 또는 2개]            ← 파란 pill + (선택)고스트 pill
[미디어]                      ← product-shadow
```
세로 패딩 80px 고정. 텍스트 폭 max 980px, 미디어 타일은 풀블리드.

## 4. 페이지 아키타입 (5종 — 모든 페이지는 이 중 하나)

각 페이지를 새로 설계하지 않는다. 아래 5개 틀에 콘텐츠만 갈아끼운다.

### A. 홈 — "타일 스택형"
풀블리드 타일 8~10개가 라이트/다크 교차하며 스택. (상세: `01_홈.md`)

### B. 서비스/솔루션 상세 — "랜딩형"
```
페이지 히어로(파치먼트, 카피만) → 문제 제기(라이트) → 해결·방법(다크 타일)
→ 성과 근거(파치먼트, 숫자/사례) → 프로세스(라이트) → 관련 인사이트 3 + 관련 성과 2
→ 최종 CTA(다크) → 푸터
```
- 각 서비스는 반드시 **[문제 → 방법 → 증거 → 행동]** 4비트를 갖는다.
- 하단에 관련 `/insights` 3 + `/work` 2 (PLAN 내부링크 설계).

### C. 목록 — "카드 그리드형" (성과/인사이트/커뮤니티 목록)
```
페이지 헤더(파치먼트) → 필터/카테고리 탭 → 카드 그리드(라이트) → 페이지네이션
```
- 성과 카드 = 썸네일 + 클라이언트 + 핵심 지표 1개(예 "ROAS 340%").
- 인사이트 카드 = 카테고리 + 제목 + 발췌 + 날짜.

### D. 상세 본문 — "리딩형" (인사이트 글/성과 케이스/회사소개)
design-system.md의 `.subpage__content` 규칙. max 980px, 리드 문단 28px muted, 본문 17px.

### E. 폼 — "문의형" (contact)
```
페이지 헤더(파치먼트) → 좌: 폼 / 우: 연락처·신뢰요소(2단, 모바일 세로) → 푸터
```

## 6. 아나키 사용 규칙 ⚠️ (대웅 지시: "신뢰도 조금 높이려 빌려쓴다. 대문짝만하게 X")

- **홈에서는 은은하게.** 큰 전용 섹션 금지. 허용: (a)통계 스트립에 구독자 수 1줄, (b)하단에 얇은 밴드 1개("총괄이사 아나키 유튜브 →"). 그 이상 크게 다루지 않는다.
- **제대로 다루는 곳은 `/company/anarchy` 한 페이지뿐.** 여기서 채널·구독자·영상 임베드.
- 표기: 이 회사(제이커브) 맥락에서는 **"아나키"** 유지. 개인 브랜드 '제스토코스트'와 별개 트랙 — 혼용하지 않는다.
- 숫자(확정): 구독자 5.06만 / 영상 248개 / 누적 조회 2,398,132회 / 개설 2011-11-15.
- 목적은 **신뢰 보강**이지 주인공 승격이 아니다. 에이전시가 주인공, 아나키는 각주다.
- ⚠️ **[검증 V4] 직함 리스크**: 아나키(개인)를 회사 사이트에 "총괄이사"로 못 박으면, 대웅이 개인 브랜드
  제스토코스트로 활동할 때 임원 신분과 충돌할 수 있다. **홈에서는 직함 없이 "함께하는 채널"**로 표기하고,
  `/company/anarchy`에서만 직함(총괄이사/파트너/자문 중 대웅 확정)을 노출한다. 직함은 blade 변수로 분리.

## 7. 접근성·성능 가드레일 (전 페이지)

- 모든 인터랙티브 요소 포커스 링(design-system: outline 2px --primary-focus).
- 비디오/애니메이션은 `prefers-reduced-motion`에서 정지 이미지 폴백(디자인시스템·PLAN 공통).
- 이미지 aspect-ratio 예약(CLS 0), 히어로 LCP는 poster로 확보(PLAN 7장).
- 색만으로 정보 전달 금지(액션블루 링크는 밑줄/맥락 병행).
- 카피 대비: 다크 타일 본문은 --on-dark, 보조는 --muted-on-dark(회색 위 회색 금지).
