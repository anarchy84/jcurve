## 0. TL;DR

1. **새로 만들지 않는다.** j-curve.co.kr 도메인 + 이 Laravel 레포(v1)를 그대로 이어간다. 사이트명은 **제이커브인터렉티브** 유지.
2. v1은 "9개 사업영역을 나열한 종합 에이전시"다. v2는 이것을 **"매체(앱)부터 CRM까지 직접 만든 회사"라는 하나의 스택 이야기**로 묶는다. 리워드 네트워크는 서비스 카드 1장에서 **핵심 축**으로 올린다.
3. 경쟁사가 이미 선점한 말("개발사 직접 실행", "셀프 집행")로는 못 이긴다. 이길 수 있는 축은 세 가지다.
   - **자체 매체 공개**: 사임캐시·꼬꼬농장
   - **정책 준수 센터**: `/trust`
   - **원천 데이터 칼럼**: 매일 발행
4. 런칭 전 필수 작업 4가지(P0)를 처리해야 한다.
   - 스테이징(dev.j-curve.co.kr) 색인 차단
   - sitemap·RSS 실구현
   - 칼럼 어드민
   - 리다이렉트 전수 검증
5. **워드프레스는 걷어내도 된다.** SEO 자산은 워드프레스가 아니라 도메인·URL·백링크·본문에 붙어 있다. 단, §7의 조건 4개를 지킬 때만이다.

## 3. 포지셔닝 v2

### 3-1. 시장 구조와 우리 위치 (리서치 요약)

- **리워드 네트워크 그룹**(애디슨·버즈빌·그린피·애드팝콘 등): 매체 규모 숫자로 신뢰를 산다. 소상공인용 언어는 없다. 버즈빌은 2025-11 셀프 광고센터를 열며 셀프 집행 영역에 진입했다.
- **셀프마케팅 그룹**(캐시플랜·셀프마케팅.com·몬스 등): 건당 단가와 가입 쿠폰으로 전환을 만든다.
  - "500개+ 매체", "대형 매체사 제휴"라고만 쓰고 어떤 앱의 어떤 유저인지는 공개하지 않는다.
  - 셀프마케팅.com은 이미 **"개발사 직접 실행"**을 쓰고 있다.
- **두 그룹이 공통으로 비워둔 자리**
  1. 매체 투명성
  2. 상품별 정책 대조
  3. 원천 데이터 리포트
  4. 실명 저자
  5. 세 고객군(앱 매체사 / 광고주 / 소상공인·셀러) 동시 응대

### 3-2. 메인 메시지

> **"트래픽이 나오는 앱부터 계약을 관리하는 CRM까지, 제이커브가 직접 만들었습니다."**
> 서브: 어떤 앱의 어떤 유저가 참여하는지 공개하고, 플랫폼 정책을 지키는 방식만 운영합니다.

제이커브 스택 = 브랜드명 그대로 **J커브를 만드는 5단 레이어**:

| 레이어 | 하는 일 | 제이커브가 직접 만든 것 |
|---|---|---|
| ① 매체 | 유저가 머무는 지면 | 사임캐시, 꼬꼬농장 (자체 리워드 앱) |
| ② 네트워크 | 광고주 액션 ↔ 매체 수익 연결 | 리워드 네트워크·오퍼월 |
| ③ 노출 | 검색·AI·플랫폼 노출 | SEO·AEO·GEO, 쇼피트렌드·부스팅샵(셀프), 랭크프리(데이터) |
| ④ 전환 | 성과형 광고·DB | 퍼포먼스 마케팅, CPA |
| ⑤ 세일즈 | 리드를 계약으로 | 리드베이(구매 측), 콜투세일(공급 측) |

### 3-3. 차별점 3개 (주장은 증거와 세트로만)

| 차별점 | 사이트에서의 증거 | 경쟁사 상황 |
|---|---|---|
| 1st-party 매체 공개 | 자체 앱명·스토어 링크·MAU·유저 분포 (**집계 기준일 병기**) | 셀프마케팅 업체는 매체 비공개, 네트워크 업체는 소상공인 상품 없음 |
| 정책 준수 센터 `/trust` | 상품별 네이버·공정위·구글플레이 정책 대조표, 무효전환 기준, 광고 표시 가이드 | 20곳 중 해당 페이지 없음 (리서치 확인 범위) |
| 원천 데이터 칼럼 | 매일 칼럼 + 월간 리포트 (오퍼 유형별 완료율 등 자사 집계) | 정기 데이터 리포트 발행처 확인 안 됨 |

### 3-4. 카피 규칙 (전 페이지·칼럼 공통)

네이버는 2025-06-26부터 리워드 앱을 이용한 검색 결과 변동 행위를 금지행위로 명시했다. 2026-02에는 토스 리워드 광고를 수사 의뢰했다. 아래 표현 규칙은 그래서 필요하다.

| 쓰지 않음 | 대신 |
|---|---|
| 상위노출 보장, N일 안에 순위 상승 | 참여형 광고로 실제 앱 사용자에게 알립니다 (성과 비보장 명시) |
| 어뷰징 0%, 제재 걱정 없음 | 플랫폼 이용정책 검토를 거친 미션만 운영합니다 + `/trust` 링크 |
| 국내 1위, 최초, No.1 | 출처·기준일 붙은 자사 수치 |
| 트래픽 구매, 순위 작업 | 앱 설치·실행 캠페인, 브랜드 인지 미션, 소식받기 참여 캠페인 |
| 리뷰·구매평 작업 | 취급 안 함 (체험단은 광고·협찬 표기 의무 안내) |

> ⚠️ 셀프마케팅 상품 중 **네이버 검색·쇼핑 순위와 연동되는 미션**을 사이트에 노출할지는 법률 검토 후 결정 (D4).

## 5. SEO · GEO v2 (SEO-SPEC v1에 추가되는 것만)

| # | 항목 | 내용 | 우선 |
|---|---|---|---|
| S1 | 스테이징 색인 차단 | dev 환경에 `X-Robots-Tag: noindex, nofollow` 헤더 + HTTP 기본 인증. robots.txt Disallow만으로는 이미 수집된 URL이 안 빠지므로 **헤더 방식** | P0 |
| S2 | sitemap 실구현 | spatie 패키지로 `sitemap.xml` 인덱스 + pages/services/insights/works/community 분할. 저장 이벤트 시 재생성. lastmod는 실제 수정일 | P0 |
| S3 | RSS | `/rss` (insights 최신 50편) — 네이버 서치어드바이저 RSS 제출용 | P0 |
| S4 | IndexNow | 칼럼 발행·수정 시 ping (네이버·Bing 참여). 키 파일 루트 배치 | P1 |
| S5 | 엔티티 그래프 | `Organization`(#org)에 자체 제품 연결: 쇼피트렌드·랭크프리·리드베이·콜투세일 = `SoftwareApplication`, 사임캐시·꼬꼬농장 = `MobileApplication`, 모두 `publisher → #org`. **각 자체 사이트 푸터에 "운영: (주)제이커브인터렉티브" 링크 + sameAs 상호 연결** → AI가 "OO 운영사"를 물을 때 제이커브로 연결 | P1 |
| S6 | 칼럼 신뢰 신호 | `Article.author → Person(아나키)`, 검수자 표기(`reviewedBy`), datePublished/dateModified 실제값, 출처 링크 목록 | P0 (어드민과 함께) |
| S7 | llms.txt | v1 결정(제거) 유지. 대규모 조사에서 AI 인용 효과 근거 없음 | — |

### 6-2. 글 1편 필수 구성 (검수 체크리스트와 동일)

1. 맨 위 정의 문단 40~60단어. 질문에 대한 결론을 먼저 쓴다.
2. 질문형 H2 3~5개.
3. **자사 데이터 블록 1개 이상** (수치 + 집계 기준 + 기준일). 이게 없으면 검수 통과 불가.
4. 정책·출처 원문 링크 (네이버 공지, 공정위 지침, 구글 문서 등).
5. 실행 체크리스트.
6. 관련 서비스 페이지 링크 1개. 앵커 텍스트는 타겟 키워드로.
7. 저자(아나키) · 검수자 · 최종 수정일 표시.

- 지역명·업종명만 바꾼 템플릿 대량 페이지. 구글 scaled content abuse 정책에 해당한다.
- 금지어: 무조건, 100%, 대박.
- 출처 없는 수치.

### 6-3. 파이프라인 (사람 검수 게이트 고정)

```
[월요일] 주간 주제 백로그 7개
   소스: 네이버 키워드 도구 · 서치콘솔 쿼리 · 문의(leads) 로그 · 커뮤니티 질문

      ↓  (자사 데이터 칸 비어 있으면 review로 못 넘어감)

      ↓

      ↓
```

- 주식·코인 DB 등 현재 사업 메시지와 거리가 먼 글은 서치콘솔 데이터를 받은 뒤 갱신 / 유지 / noindex로 판정한다. 노출 있는 글은 지우지 않는다.

## 7. 워드프레스 철거 판단

**결론: 철거 OK.** 이유는 세 가지다.

- 검색 신호는 도메인 이력·URL·백링크·본문 내용에 붙어 있다. 워드프레스라는 플랫폼에 붙어 있지 않다.
- 현 WP의 실제 콘텐츠는 글 3편 + 페이지 15개 + 백링크 상품 3개다. 이미 `database/content/legacy/`에 수집돼 있다.
- WP에는 Avada 데모 더미(라틴어 포트폴리오 13개, 2015년 데모 로그인 페이지)와 사이트맵 2중(Rank Math + Jetpack)이 남아 있다. 철거가 오히려 품질 신호를 정리한다.

**조건 4개 (하나라도 빠지면 런칭 보류)**

1. URL-MIGRATION §A·B 전 URL **1홉 301 + 도착 페이지 200** curl 전수 통과.
2. 도착 페이지에 원문·실적 수치 이식 완료. 빈 도착 페이지는 소프트 404로 취급된다.
3. WP + 그누보드 풀백업. 구 서버·DB는 **최소 3개월 보존**하고, 도큐먼트루트를 원복하는 롤백 경로를 문서화한다.
4. 런칭 전 서치콘솔 클릭 상위 URL 목록 확보. 런칭 후 4주간 해당 URL의 순위·색인을 매일 체크한다. 2~4주 일시 변동은 정상 범위로 보고 즉시 되돌리지 않는다.

> 참고: v2 URL 정책(전량 301 → 클린 URL)은 8/4 서버 담당 확정안이다. 주소를 그대로 두는 것보다 리스크는 조금 높다. 하지만 1홉 + 본문 동일이면 신호는 승계되므로 유지한다.
