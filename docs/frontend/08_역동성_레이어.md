# 역동성 레이어 (버즈빌 스타일) — design-system 확장

> 대웅 지시(2026-08-04): **"버즈빌처럼 역동적이게. 아이콘·디자인 싹 다 힉스필드."**
> `design-system.md`(애플 미니멀·그라디언트 금지)는 **정적**이라 이 요구와 충돌한다.
> → 덮어쓰지 않고 **"역동 레이어"로 확장**한다. 클로드코드는 이 레이어를 홈·주요 랜딩에 적용.
> **하네스 검수본** (Creative Director 주도).

---

## ★ 대원칙 — "애플 뼈대 + 버즈빌 생기" (대웅 확정 2026-08-04)

> **"기존 애플 뉘앙스에 버즈빌스러움을 섞어줘."**

둘 중 하나를 고르는 게 아니라 **레이어로 합친다.**

| 층 | 담당 | 출처 |
|---|---|---|
| **뼈대**(레이아웃·타이포·여백·라이트/다크 타일·액션블루 1색) | 그대로 유지 | 애플(design-system.md) |
| **생기**(3D 아이콘·글래스 카드·orb 무드·캐러셀·마퀴·초대형 숫자) | 얹는다 | 버즈빌(이 문서) |

원칙: **정갈함은 애플에서, 역동성은 버즈빌에서.** 애플의 절제를 잃지 않되(색 1개·과장 없는 타이포),
그 위에 버즈빌의 3D·모션·글래스로 생기를 준다. 둘이 안 싸우게 하는 경계 = "크롬은 애플, 콘텐츠는 버즈빌".

---

## 0. 톤 결정 (검증 완료)

힉스필드 대표 생성으로 A/B 비교 → **톤 B 채택.**

| 톤 | 정체 | 판정 |
|---|---|---|
| A · 애플 미니멀 추상 | 평면 라이트 웨이브 | 세련되나 **정적** → 히어로/섹션 **배경**으로만 병행 |
| **B · 3D 아이소메트릭 클레이** ⭐ | 유리+매트 3D 아이콘 | **버즈빌 역동성의 핵심.** 전 아이콘 이 톤으로 통일 |

- 브랜드 일관성: 컬러는 **우리 액션블루(#0066cc) 유지** + 포인트에 웜 액센트 소량(버즈빌 레드 대용).
- A톤 다크+블루 웨이브 = 히어로/CTA **배경 무드**(orb 대용)로 재활용.

## 1. 확장 토큰 (design-system.md에 추가)

```
/* 역동 레이어 — 애플 미니멀 위에 얹는 다이내믹 토큰 */
--orb-blue: radial-gradient(circle, rgba(0,102,204,.35), transparent 70%);   /* 배경 구체 글로우 */
--orb-deep: radial-gradient(circle, rgba(41,151,255,.18), transparent 70%);
--glass-fill: rgba(255,255,255,.06);         /* 글래스모피즘 카드 채움(다크 위) */
--glass-border: rgba(255,255,255,.12);
--glass-blur: saturate(160%) blur(24px);
--stat-huge: clamp(48px, 8vw, 104px);        /* 버즈빌식 초대형 숫자 */
--accent-warm: #ff7a59;                       /* 3D 아이콘 포인트(아주 소량) */
```
> ⚠️ design-system의 "그라디언트 금지"는 **UI 크롬 한정**으로 완화. orb는 **배경 무드**로만 허용
> (버튼·카드 표면엔 여전히 그라디언트 금지). 이 경계를 지키면 두 시스템이 공존한다.

## 2. 역동 컴포넌트 5종 (버즈빌에서 가져온 것)

### C1 — Orb 글로우 배경
```
near-black 섹션 뒤에 큰 원형 블루 글로우 1~2개(--orb-blue), blur 크게.
스크롤 시 서서히 이동(parallax). reduce-motion 시 정지.
→ 홈 히어로·통계·최종CTA 등 다크 섹션 배경.
```

### C2 — 3D 아이소메트릭 아이콘 (힉스필드) ⭐
```
모든 기능/서비스/통계 아이콘 = B톤 3D 클레이 아이콘. PNG 투명배경.
카드 안에서 살짝 floating 애니메이션(위아래 4px, 3s ease-in-out). reduce-motion 정지.
```

### C3 — 글래스모피즘 bento 그리드
```
비대칭 카드 그리드(버즈빌 "광고로 끝나지 않고" 섹션). 큰 카드+작은 카드 조합.
카드 = --glass-fill + 1px --glass-border + backdrop --glass-blur + radius 20.
각 카드에 초대형 숫자(--stat-huge) 또는 3D 아이콘.
```

### C4 — 가로 스크롤 캐러셀
```
서비스/성과/솔루션을 가로 카드 캐러셀로(버즈빌 폰목업 캐러셀). 좌우 화살표 + 드래그.
카드가 중앙에서 살짝 커지는 focus 효과. 모바일 스와이프.
```

### C5 — 마퀴(흐르는 로고·아이콘 띠)
```
클라이언트 로고월 + (있으면)매체 아이콘을 무한 가로 흐름(버즈빌 로고 마퀴).
2줄 역방향 흐름. hover 시 일시정지. reduce-motion 시 정적 그리드로 폴백.
→ 홈 S2 신뢰 스트립을 마퀴로 업그레이드.
```

## 5. 성능 가드 (역동성의 대가)

버즈빌식 효과는 무거울 수 있다. PLAN CWV 방어선 유지:
- orb·마퀴·floating = CSS transform/opacity만(레이아웃 리플로우 금지).
- 3D 아이콘 = WebP, 적정 해상도(과대 금지). lazy-load.
- **`prefers-reduced-motion`: 마퀴·캐러셀 자동재생·floating·orb 이동 전부 정지.**
- 캐러셀은 JS 최소(Embla 등 경량) 또는 CSS scroll-snap.
