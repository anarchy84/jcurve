## ⚠️ 라우트/구조 변경 지시 (클로드코드)

기존 PLAN·라우트에는 `/company/anarchy` 별도 페이지가 있었으나 **폐지**한다.

```php
// 기존
Route::get('/company/anarchy', ...)->name('company.anarchy');  // ← 제거 또는 앵커 리다이렉트

// 변경 후
Route::get('/company', [PageController::class,'company'])->name('company');  // 유지, 아나키 섹션 내장
// company.anarchy 로의 기존 링크·301은 → /company#anarchy 앵커로 통일
```
- 홈 S9 아나키 밴드 링크: `route('company.anarchy')` → **`route('company').'#anarchy'`** 로 변경.
- 내비 '회사' 드롭다운의 '아나키' 하위항목: 유지하되 목적지를 `/company#anarchy` 로.
- `anarchy.blade.php`(별도 뷰)는 제거하고 company.blade.php 안 섹션으로 흡수.

## S5. ⭐ 아나키 섹션 [파치먼트] — 작게 (id="anarchy")

대웅 지시: **회사소개 중간에 작게.** 큰 전용 페이지 아님. 총괄이사 직함 유지.

```
소제목:  총괄이사가 직접 운영하는 유튜브 채널
본문:    마케팅 현장의 이야기를 콘텐츠로 풉니다. 이론이 아니라 실제로
         돌려본 것만 다룹니다. 유튜브 채널 '아나키'.
지표:    구독 5.06만 · 영상 248개 · 누적 조회 239만+   {{-- CONTENT.md 확정 --}}
CTA:     [채널 보기 →]  → youtube.com/@아나키 (외부, 새 탭)
```
- **레이아웃**: 좌 텍스트 + 우 채널 썸네일/최신영상 1개(lite-youtube, 성능보호). 세로 비중 낮게.
- 영상 임베드는 최대 1개. 채널 전체를 홍보하는 큰 그리드 금지(작게 규칙).
- 직함 "총괄이사" 표기 유지(대웅 확정). 개인 브랜드 제스토코스트는 여기서 언급하지 않음(별개 트랙).
- Person 스키마(JSON-LD)는 이 섹션 기준으로 생성 가능(PLAN SEO).
