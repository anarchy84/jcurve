# 문의 페이지 기획안 (`/contact`) — 마지막

> 아키타입 E(문의형). `00_마스터_UX.md` 준수.
> **하네스 검수본** — 폼 필드는 이미 구현 우수(이름·회사·이메일·전화·관심서비스·내용 + honeypot + 검증).
> 비어 있는 것: **2단 레이아웃 · 개인정보 동의 · 신뢰 요소.** 이 3개를 채운다.

---

## 레이아웃 [아키타입 E — 2단, 모바일 세로]

```
[파치먼트] 페이지 헤더
  H1:   프로젝트 문의
  리드:  목표와 현재 상황을 알려주시면, 적합한 실행 방향을 검토해 연락드립니다.

[라이트] 2단 (좌 60% : 우 40%, 833px↓ 세로 스택)
  ┌─────────────────────────┬──────────────────────┐
  │ 좌: 문의 폼 (기존 필드 유지) │ 우: 연락·신뢰 패널      │
  └─────────────────────────┴──────────────────────┘
```

## 좌 — 폼 (기존 유지 + 2개 보강)

기존 필드 그대로: 이름* / 회사명 / 이메일* / 전화번호 / 관심 서비스* / 문의 내용*

**보강 1 — 관심 서비스 옵션에 솔루션 추가** ⚠️
현재 select는 서비스 5개뿐. 솔루션·기타 추가:
```
퍼포먼스 마케팅 / CPA 마케팅 / 리워드 네트워크 / SEO·AEO·GEO / 워드프레스
─ 랭크프리 / 부스팅샵 / 리드베이 / 콜투세일     ← 신규
─ 기타·잘 모르겠음                              ← 신규 (진입장벽 낮춤)
```
> "기타·잘 모르겠음"은 하네스 Growth: 뭘 골라야 할지 몰라 이탈하는 리드를 잡는다.

**보강 2 — 개인정보 수집 동의 (법적 필수)** ⚠️⚠️
leads 테이블에 개인정보(이름·이메일·전화)를 저장하므로 **동의 체크 필수.**
```
[ ] (필수) 개인정보 수집·이용에 동의합니다.  [자세히](→ /privacy)
    수집 항목: 이름·이메일·전화·회사명 / 목적: 문의 응대 / 보유: 목적 달성 후 파기
[ ] (선택) 마케팅 정보 수신에 동의합니다.
```
- 필수 동의 없으면 제출 불가(서버·클라 양쪽 검증).
- 클로드코드: `leads` 저장 시 `privacy_agreed_at`, `marketing_agreed`(bool) 컬럼 추가 권장.
- ⚠️ [Client Risk] 이거 빠지면 개인정보보호법 위반. **런칭 전 반드시.**

## 우 — 연락·신뢰 패널 [파치먼트 카드]

```
빠른 연락:
  · 전화  02-1668-2612
  · 이메일 jcurve19@gmail.com
  · 주소  서울 금천구 가산디지털1로, 가산더블유센터 703호

응답 안내:
  영업일 기준 1~2일 내 담당자가 연락드립니다.   {{-- [검증] 실제 응답속도 대웅 확인 --}}

신뢰 요소:
  · 함께한 브랜드 로고 3~4개(그레이스케일, 홈 로고월 축약)
  · "2009년 설립 · 누적 373억 집행"   {{-- 회사 기준값 --}}
```
> ⚠️ [검증] "1~2일 내 응답"은 실제 운영 기준 확인 필요. 못 지키면 신뢰 역효과 → 대웅 확정 전엔 "빠르게 연락드립니다"로.

## 제출 후 (UX)

```
성공:  "문의가 접수되었습니다. 영업일 기준 1~2일 내 연락드리겠습니다."
       (기존 session('status') 활용, role="status")
실패:  필드별 인라인 에러(기존 @error 유지) + 상단 요약
스팸:  honeypot(기존) + throttle:5,1(기존 라우트) 유지
```
- 성공 시 전환 추적(GTM/GA4 이벤트) 훅 지점 표시 — PLAN 트래킹.
- 확인 이메일 자동발송(선택, leads 후속).

---

## 접근성
- 모든 input에 label 연결(기존 OK), 필수는 `required` + 시각 표시(*).
- 에러는 `role="alert"`, 성공은 `role="status"`(기존 OK).
- 동의 체크박스도 label 연결 + 키보드 접근.
