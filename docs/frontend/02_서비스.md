## 공통 랜딩 골격 (5개 서비스 전부 이 뼈대)

```
[파치먼트] 페이지 히어로       — 라벨 + H1(주키워드) + 리드 1문장 + [문의] CTA
[라이트]   ① 문제 제기         — 고객이 겪는 진짜 페인 (질문형 소제목)
[다크]     ② 방법·해결         — 제이커브가 어떻게 하는가 (3~4 포인트)
[파치먼트] ③ 증거             — 숫자·사례·프로세스 (신뢰)
[라이트]   ④ 하위 영역 카드     — (하위 있는 서비스만) 세부 랜딩으로
[파치먼트] ⑤ 관련 인사이트 3 + 관련 성과 2   — PLAN 내부링크
[다크]     ⑥ 최종 CTA
```
- 각 서비스 = **[문제 → 방법 → 증거 → 행동]** 4비트 필수.
- 톤: 홈과 동일(에디토리얼·조용한 권위). 감탄사 훅 금지.
- 하위 랜딩(예: /services/cpa-marketing/stock)은 **같은 골격의 축소판** — 히어로+방법+CTA 3섹션이면 충분.

### 실적 수치 배분 규칙 ⚠️ [검증 V2]
누적 광고비 373억·DB 128만·캠페인 15,700은 **회사 전체 누적값**이다(CONTENT.md).
서비스별 페이지에서 "이 서비스로 373억"처럼 **특정 서비스에 전액 귀속시키지 않는다.**
→ 서비스 페이지에서는 "제이커브 누적 기준"으로 표기하거나, 해당 서비스 실측이 없으면 숫자 생략.
클로드코드는 서비스별 개별 실적이 seed로 들어오기 전까지 회사 누적값만 "회사 전체" 라벨로 사용.

## 2. CPA 마케팅 — `/services/cpa-marketing`

**주키워드**: CPA 마케팅 / 타깃**: 광고비 리스크를 줄이고 "성과당 과금"을 원하는 광고주.
**하네스 크리에이티브 각도**: CPA의 본질 = "돈 낭비 공포 제거". 훅을 거기 맞춘다.

### 히어로 [파치먼트]
```
라벨:  CPA MARKETING
H1:    CPA 마케팅 — 성과가 난 만큼만 비용이 발생합니다
리드:  설치·가입·구매·상담신청. 실제 액션이 일어난 만큼만 과금하는
       성과형 광고를 설계하고 운영합니다.
CTA:   [CPA 상담 요청]  → contact
```

### ① 문제 [라이트]
```
소제목:  "노출은 샀는데, 전환이 안 왔다."
본문:    노출·클릭 단가로 광고를 사면 리스크는 광고주가 다 집니다.
         클릭이 많아도 가입 한 건이 없으면 그대로 손실입니다.
```

### ② 방법 [다크]
```
소제목:  액션 단위로 과금 구조를 다시 짭니다
포인트:
  · 전환 정의 합의 — 무엇을 '성과'로 볼지(설치/가입/구매/DB) 먼저 확정
  · 트래킹 세팅 — 픽셀·포스트백·서버 이벤트로 전환을 정확히 귀속
  · 매체 소싱 — CPA에 맞는 인벤토리(리워드 네트워크 포함)로 물량 확보
  · 어뷰징 필터 — 무효 전환 걸러 실제 성과만 정산
```

### ③ 증거 [파치먼트]
```
· 업종별 CPA 랜딩 다수 운영(부동산·주식·보험·코인·퍼미션콜) — 카테고리별 노하우 축적
· 리워드 네트워크 자체 연동(→ 리워드 네트워크 페이지) — CPA 물량 소싱에 강점
```

### ④ 하위 영역 카드 [라이트]
| 카드 | 링크 |
|---|---|
| 부동산 분양 CPA | `/services/cpa-marketing/real-estate` |
| 주식 DB 마케팅 | `/services/cpa-marketing/stock` |
| 보험 DB | `/services/cpa-marketing/insurance` |
| 코인 DB | `/services/cpa-marketing/coin` |
| 퍼미션콜 DB | `/services/cpa-marketing/permission-call` |

> ⚠️ [검증] 금융·주식·코인 DB 마케팅은 **표시광고·개인정보·유사수신 규제**에 민감하다.

## 3. 리워드 네트워크 — `/services/reward-network`

**주키워드**: 리워드 광고 / 리워드 네트워크 / 타깃**: 앱 설치·액션 물량이 필요한 광고주 + 매체(앱) 제휴.
**⚠️ 경쟁사명(버즈빌·애드팝콘·NBT)은 meta·title 금지**(PLAN 4장). 본문에서 "리워드 네트워크 카테고리"로만.

### 히어로 [파치먼트]
```
라벨:  REWARD NETWORK
H1:    리워드 네트워크 — 액션을 만드는 광고
리드:  사용자가 리워드를 받고 앱 설치·회원가입·미션을 완료합니다.
       광고주에게는 실제 액션이, 매체에는 수익이 남는 구조입니다.
CTA:   [광고주 문의]  ·  [매체 제휴 문의]   → contact (유형 구분)
```

### ① 문제 [라이트]
```
소제목:  "설치 수는 늘었는데, 진짜 유저가 없다."
본문:    단순 노출형 광고는 '보기만 한' 유저를 데려옵니다.
         리워드 네트워크는 실제로 행동한 유저를 데려오되, 그 행동의 '질'을
         관리하지 못하면 어뷰징만 남습니다. 관건은 네트워크 운영 능력입니다.
```

### ② 방법 [다크]
```
소제목:  광고주와 매체, 양쪽을 직접 운영합니다
포인트:
  · 광고주 측 — 목표 액션(CPI/CPA/CPE) 설계 + 물량·단가 최적화
  · 매체(앱) 측 — 오퍼월·리워드 지면 연동, 수익화 세팅
  · 품질 관리 — 어뷰징·무효 전환 필터로 실 유저만 정산
  · 리포팅 — 액션별 전환·리텐션까지 추적(설치 후 잔존 관점)
```

### ③ 증거 [파치먼트]
```
· 광고주·매체 양방향 운영 경험 — 네트워크사 카테고리(리워드 광고 전문사)로 포지셔닝
· CPA 마케팅과 연계 — 리워드 인벤토리를 CPA 물량 소싱에 활용
```

### ⑥ CTA [다크]
```
H:   광고주라면 액션을, 매체라면 수익을 — 양쪽 다 상담합니다
CTA: [광고주 문의]  [매체 제휴 문의]  → contact
```
> 하위 페이지 없음. 대신 `/insights`에 "리워드 네트워크 비교" 아티클로 롱테일+경쟁사 롱테일 흡수(PLAN 4장).

## 4. SEO · AEO · GEO — `/services/seo` ⭐ 핵심 차별 페이지

**주키워드**: SEO 대행 / 검색엔진최적화 업체 / 타깃**: 광고비 말고 자연 유입을 원하는 기업.
**⭐ 이 페이지가 곧 포트폴리오** — "이 사이트가 검색 상위에 뜬 것 자체가 증거"(PLAN 차별점 2). 강하게.

```
         검색 유입은 한 번 자리를 잡으면 광고비 없이 계속 들어옵니다.
         문제는 SEO가 느리고, 대부분의 업체가 '백링크 몇 개'로 끝낸다는 것입니다.
```

```
  · GEO(생성엔진) — ChatGPT·Perplexity 답변에 브랜드가 언급되도록 최적화
플랫폼:  구글 · 네이버 쇼핑 · 네이버 플레이스 · 쿠팡 · 카카오 선물하기
```

```
소제목:  "홈페이지는 만들었는데, 아무도 안 들어온다."
본문:    외주로 만든 사이트 대부분은 SEO가 비어 있습니다. 예쁘지만 검색에
         안 잡히면, 결국 또 광고비를 써야 유입이 생깁니다.
```

### ② 방법 [다크]
```
소제목:  제작 단계부터 SEO를 심습니다
포인트:
  · SEO 내장 — 구조화데이터·속도·시맨틱 마크업을 처음부터
  · 확장 구조 — 블로그·랜딩·다국어까지 붙일 수 있는 설계
  · 운영·유지보수 — 만들고 끝이 아니라 성장까지 관리
  · 마케팅 연결 — 퍼포먼스·SEO팀과 같은 회사라 유입 전략까지 한 번에
```

```
· 기존 "홈페이지 제작" 서비스 실적 승계(CONTENT.md)   {{-- [검증] 실적 확인 --}}
```

## 하위 랜딩 처리 방침 (클로드코드용)

URL-MIGRATION §C의 하위 페이지들(퍼포먼스 3 · CPA 5 · SEO 5 = 13개)은 **301 도착지**라
빈 페이지면 소프트404가 된다. 하지만 **한 번에 다 리치하게 채우지 않는다.**

| 단계 | 처리 |
|---|---|
| 1차(지금) | 하위 랜딩 = **히어로(H1+리드) + 방법 3포인트 + CTA** 최소 3섹션. 소프트404만 면함 |
| 2차 | 반응·검색 데이터 보고 트래픽 있는 하위부터 리치 확장 |
| ⚠️ CPA 금융계열(주식·보험·코인·부동산·퍼미션콜) | **법무 확인 전까지 카피 생성 보류.** 히어로+CTA만 |

- 각 하위 랜딩 카피는 **다음 배치(별도 요청)** 에서 하네스 검수 후 제공. 이 문서엔 메인 5개만 완성.
