# 1. 퍼포먼스 마케팅 — 냉정한 애널리스트

**구조 변경: 숫자부터 던지고 시작한다. 문제 제기는 그 다음.**

### 히어로
```
eyebrow: Performance Marketing
H1: 광고비의 성적표를 만들어 드립니다
lead: 373억. 저희가 지금까지 집행한 광고비입니다.
      이 돈이 가르쳐준 건 하나였습니다 — 감으로 배분한 예산은 반드시 샌다.
CTA: [내 광고 성적 진단받기]
```

### ① 숫자 스트립 (신설 — 문제보다 먼저)
```
373억+   누적 집행 광고비 (회사 전체 기준)
15,700+  캠페인 수
주 단위   예산 리밸런싱 주기
```

### ② 문제 — 시나리오 서술형
```
H2: 리포트는 화려한데, 통장은 조용한 이유

월말 리포트를 열어봅니다. 노출 300만, 클릭 4만, CTR 양호.
그런데 이상하죠. 매출은 그대로입니다.

이유는 단순합니다. 그 리포트에 '매출'이 없기 때문입니다.
노출과 클릭은 광고회사의 성적이지, 사장님의 성적이 아닙니다.
저희는 처음부터 다른 숫자를 봅니다. 광고비 1원이 매출 몇 원이 됐는가 — ROAS.
그거 하나만 봅니다.
```

### ③ 방법 — 프로세스 서술 (기존 4포인트를 확장)
```
H2: 예산이 새는 곳을 찾고, 이기는 곳으로 옮깁니다

1. 전환 정의부터 다시 합니다
   "우리한테 성과란 무엇인가"를 먼저 합의합니다. 매출인지, 가입인지, 상담신청인지.
   이게 정해져야 나머지 전부가 의미를 갖습니다.

2. 매체를 한 판 위에 올립니다
   메타·구글·네이버·유튜브 성과를 한 대시보드에서 봅니다.
   같은 전환을 두 매체가 서로 자기 성과라고 우기는 중복 귀속부터 걷어냅니다.

3. 주 단위로 예산을 옮깁니다
   지는 소재는 끕니다. 이기는 소재에 몰아줍니다. 월말 정산이 아니라 주 단위 리밸런싱.
   광고비가 낭비되는 최대 원인은 '나쁜 광고를 한 달 내내 튼 것'입니다.

4. 소재는 사내에서 만듭니다
   촬영·편집·디자인 내재화. 외주 대기 없이 이번 주 데이터로 다음 주 소재를 만듭니다.
```

### ④ FAQ (신설)
```
Q. 광고비가 적어도 되나요?
   월 예산 규모보다 '전환 데이터가 쌓이는 속도'가 중요합니다. 예산이 작으면
   테스트 설계를 다르게 합니다. 상담 때 예산부터 말씀해 주세요. 그에 맞는 판을 짭니다.

Q. 기존 대행사에서 옮기면 뭐가 달라지나요?
   인수인계 첫 주에 계정 구조 진단부터 합니다. 대부분 여기서 새는 구멍이 나옵니다.
   진단 결과는 옮기지 않으셔도 드립니다.

Q. 리포트는 어떻게 받나요?
   주간 단위. 노출·클릭이 아니라 전환·ROAS 중심으로. 나쁜 숫자도 그대로 보냅니다.
```

### CTA
```
H2: 지금 광고, 성적표부터 만들어 보세요
sub: 계정 열어주시면 어디서 새는지 짚어드립니다. 옮기지 않으셔도 진단 결과는 드립니다.
CTA: [성과 진단 요청]
```

# 2. CPA 마케팅 — 명료한 딜메이커

**구조 변경: 과금 구조 표부터. 계약서처럼 명료하게.**

### 히어로
```
eyebrow: CPA Marketing
H1: 성과가 없으면, 비용도 없습니다
lead: 노출당 과금이 아니라 액션당 과금.
      설치 1건, 가입 1건, 상담신청 1건 — 일어난 만큼만 계산하는 구조입니다.
CTA: [CPA 구조 상담]
```

### ① 과금 구조 비교표 (신설)
```
H2: 어디에 돈을 내는 구조인지부터 보시죠

| 구분 | 일반 디스플레이 광고 | CPA |
|---|---|---|
| 과금 시점 | 노출·클릭 발생 시 | 정의된 액션 완료 시 |
| 리스크 부담 | 광고주 | 매체·네트워크 |
| 성과 없을 때 | 광고비 소진 | 비용 0 |
| 적합한 목표 | 인지도 | 설치·가입·DB·구매 |

광고주 입장에서 CPA의 본질은 하나입니다. 리스크의 이동.
"보여주는 값"이 아니라 "일어난 값"을 내는 것.
```

### ② 조건 — 정직하게
```
H2: 대신, 조건이 있습니다

CPA가 만능은 아닙니다. 세 가지가 갖춰져야 돌아갑니다.

하나. 액션 정의가 명확할 것 — '설치'인지 '가입'인지 '결제'인지. 모호하면 정산 분쟁이 됩니다.
둘. 트래킹이 정확할 것 — 픽셀·포스트백·서버 이벤트. 측정 안 되는 액션은 과금할 수 없습니다.
셋. 단가가 시장가일 것 — 액션당 단가가 너무 낮으면 물량이 안 붙습니다. 시장가는 상담에서 투명하게 공개합니다.

이 세팅을 저희가 합니다. 그게 CPA 대행의 일입니다.
```

### ③ 업종 케이스 (하위 링크)
```
H2: 업종마다 판이 다릅니다
부동산 분양 · 주식 · 보험 · 코인 · 퍼미션콜 — 각 업종 전용 구조로 운영합니다.
{{-- ⚠️ 금융계열 하위 랜딩 본문은 법무 확인 전까지 기존 방침 유지(히어로+CTA만) --}}
```

### ④ 보험이라면 — CRM 연결 블록 (기존 유지, 문장만 교체)
```
H2: 보험 쪽이시라면, 저희는 조금 더 깊이 들어갑니다
DB를 사는 쪽을 위한 CRM(리드베이)과 파는 쪽을 위한 CRM(콜투세일)을 직접 만들어 운영 중입니다.
유입에서 끝나지 않고 상담·계약·정산까지 — 파이프라인 전체가 저희 영역입니다.
[리드베이 →] [콜투세일 →]
```

### CTA
```

sub: 목표 액션·예상 단가·물량, 상담에서 숫자로 말씀드립니다.
```

# 3. 리워드 네트워크 — 생태계 설계자

**구조 변경: 양면 시장 스토리로 전개. 광고주 트랙 / 매체 트랙 분리 섹션.**

### 히어로
```
eyebrow: Reward Network
H1: 유저는 리워드를 얻고, 광고주는 액션을 얻습니다
lead: 그 사이에서 품질을 지키는 게 네트워크의 일입니다.
      제이커브는 광고주와 매체, 양쪽을 모두 직접 운영합니다.
CTA: [광고주 문의] [매체 제휴 문의]
```

### ① 구조 설명 — 3자 관계도
```
H2: 리워드 광고는 삼각형입니다

유저 — 미션을 수행하고 포인트를 받습니다. 광고를 '당하는' 게 아니라 '참여'합니다.
광고주 — 설치·가입·미션완료, 실제 액션에만 비용을 냅니다.
매체(앱) — 오퍼월 지면을 열고 수익을 만듭니다.

셋 중 하나라도 손해 보면 무너지는 구조입니다. 그래서 네트워크 운영의 핵심은
물량이 아니라 균형입니다.
```

### ② 광고주 트랙
```
H2: 광고주께는 — '설치 수'가 아니라 '남는 유저'를

리워드 광고의 고질병을 압니다. 설치는 쏟아지는데 다음날 잔존율이 바닥인 것.
그래서 저희는 액션 설계 단계부터 다르게 갑니다.
단순 설치가 아니라 튜토리얼 완료·레벨 도달 같은 심화 액션으로 과금 지점을 미루면,
포인트만 먹고 떠나는 유저가 걸러집니다. 어뷰징 필터는 그 다음 방어선이고요.
```

### ③ 매체 트랙
```
H2: 매체께는 — 지면이 돈이 되도록

앱에 오퍼월·리워드 지면을 붙이는 순간부터 정산까지 저희가 함께합니다.
유저 이탈 없이 수익을 만드는 지면 설계, 캠페인 소싱, 투명한 리포팅.
광고주 쪽 물량을 직접 돌리고 있어서 지면에 캠페인이 마르지 않습니다.
```

# 4. SEO · AEO · GEO — 도발하는 실증가

**구조 변경: 도발 질문 → 즉시 실증 → 원리 → 상품. 가장 공격적인 페이지.**

### 히어로
```
eyebrow: SEO · AEO · GEO
H1: 이 페이지, 어떻게 찾으셨나요?
lead: 검색했더니 나왔을 겁니다. 그게 저희가 파는 상품입니다.
      제이커브의 SEO 포트폴리오 1번은 언제나 — 지금 보고 계신 이 사이트입니다.
CTA: [내 사이트도 이렇게 →]
```

### ① 실증 — 자기 증명
```
H2: 말 대신 검색 결과로 증명합니다

SEO 업체를 고르는 가장 확실한 방법을 알려드릴까요?
그 업체 이름을 검색해 보세요. 자기 사이트도 못 올리는 회사가 남의 사이트를 올려줄 리 없습니다.

저희는 10년 넘게, 1,000개가 넘는 프로젝트에서 이 일을 해왔습니다.  {{-- CONTENT.md 승계 --}}
구글·네이버뿐 아니라 네이버 쇼핑, 플레이스, 쿠팡, 카카오 선물하기까지 —
'검색되는 곳'이라면 전부 저희 무대입니다.
```

### ② 시대 전환 — AEO·GEO
```
H2: 그리고 지금, 검색의 규칙이 다시 바뀌고 있습니다

사람들이 챗GPT한테 물어보기 시작했습니다. "OO 업체 추천해줘."
AI는 어디서 답을 가져올까요? 검색 상위 문서입니다.
즉 SEO가 죽은 게 아니라, SEO가 AI 노출의 입구가 된 겁니다.

AEO — 구글 AI 개요, 네이버 AI 답변에 인용되도록 문서를 구조화합니다.
GEO — 챗GPT·퍼플렉시티의 답변에 브랜드가 언급되도록 최적화합니다.
아직 하는 곳이 드뭅니다. 그래서 지금이 선점 타이밍입니다.
```

### ③ 방법 — 3계층
```
H2: 저희가 손대는 세 개의 층

기술 층 — 크롤링, 색인, 속도(CWV), 구조화 데이터. 검색엔진이 읽을 수 있는 몸을 만듭니다.
콘텐츠 층 — 검색의도 기반 토픽 클러스터. '많이'가 아니라 '의도에 맞게' 씁니다.
신뢰 층 — 내부링크·백링크·E-E-A-T. 검색엔진이 믿을 이유를 쌓습니다. 백링크 패키지는 월 50만원부터.
```

### ① 흔한 실패담
```
H2: 500만 원짜리 유령주택 이야기

많은 사장님들이 겪는 순서가 있습니다.
제작사에 맡긴다 → 예쁜 사이트가 나온다 → 오픈한다 → ... 아무도 안 온다.

지도에 없는 집이거든요. 주소(색인)도, 표지판(구조화 데이터)도 없이 지어진 겁니다.
```

### ② 제작 공정 — 장인의 순서
```
H2: 저희가 짓는 순서

2. 뼈대 세우기 — 시맨틱 마크업, 크롤링 가능한 구조, 속도 최적화. 검색엔진이 읽는 골조.
3. 내부 공사 — 디자인·콘텐츠. 예쁜 건 기본이고, 모든 페이지가 검색 목적을 갖게 합니다.
4. 길 내기 — 색인 등록, 구조화 데이터, 사이트맵. 오픈 첫날부터 검색에 잡히게.
5. 관리 — 만들고 끝이 아니라 운영·보안·업데이트까지. 집은 관리해야 값이 오릅니다.
```

```
퍼포먼스·SEO팀이 같은 회사에 있다는 것 — 그게 실질적인 차이입니다.
```
