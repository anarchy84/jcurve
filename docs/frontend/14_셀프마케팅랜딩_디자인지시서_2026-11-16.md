## 1. 적용 범위와 원칙

### 1-1. 범위
- **이 랜딩 한 페이지만** 바꾼다. 사이트 공통 헤더(`partials/jc/header`)·푸터·카카오 떠 있는 버튼, 그리고 다른 페이지는 그대로 둔다.
- 공용 부분 파일(`partials/jc/partner-band`, `partials/jc/rank-form`)은 **고치지 않는다.** 랜딩 안에서 모양만 바꿀 때는 아래 `.jc-lp` 범위 CSS로 덮는다.
- **섹션 순서와 문구는 지금 그대로 둔다.** 마크업 구조(감싸는 태그·클래스·한 섹션 안의 배치)는 바꿔도 된다. 화면에 보이는 문장은 한 글자도 바꾸지 않는다.
  - 예외: 장식용 번호(FAQ 앞 `01`~`09`)와 버튼 화살표 아이콘을 새로 붙인다. 둘 다 `aria-hidden="true"`로 둔다.
- CSS는 `jc.css`의 `LP self-marketing` 블록(지금 1272~1321행)을 **통째로 이 문서 기준으로 바꾼다.** 다른 블록은 건드리지 않는다.

### 1-2. 범위 감싸기 — `.jc-lp`
`@section('content')` 안의 모든 섹션을 `<div class="jc-lp">…</div>` 하나로 감싼다. 랜딩 전용 값은 전부 이 클래스 아래에서만 바꾼다. 헤더·푸터는 `<main>` 밖이라 영향이 없다.

```css
.jc-lp {
    /* 글꼴: 제목·숫자도 Pretendard 하나로 (2장) — 변수만 바꾸면 .jc-display·.jc-num 을 쓰는 공용 부분까지 따라온다 */
    --jc-font-display: var(--jc-font);
    --jc-font-num: var(--jc-font);
    /* 레이아웃 (PW .wrap · 섹션 여백) */
    --jc-lp-max: 1320px;
    --jc-lp-gutter: 32px;                          /* ≤920 22px · ≤680 15px */
    --jc-lp-section: clamp(88px, 9.72vw, 140px);    /* 1440 → 140 · 375 → 88 */
    /* 선 (PW: 묶음 위 2px 진한 줄 + 항목 사이 1px 연한 줄) */
    --jc-lp-rule: 2px solid var(--jc-ink);
    --jc-lp-hair: 1px solid var(--jc-line-2);
    font-weight: 500;
    letter-spacing: -0.02em;                        /* PW 전역 -0.32px(16px 기준) */
}
.jc-lp .jc-wrap { max-width: var(--jc-lp-max); padding-inline: var(--jc-lp-gutter); }
.jc-lp .jc-section { padding: var(--jc-lp-section) 0; }
.jc-lp :is(h1, h2, h3) { text-wrap: balance; }   /* 한 단어만 넘어가는 줄 방지(부록 A) */
@media (max-width: 920px) { .jc-lp { --jc-lp-gutter: 22px; } }
@media (max-width: 680px) { .jc-lp { --jc-lp-gutter: 15px; } }
```
- `.jc-wrap`은 `box-sizing: content-box`라서 위 값이면 1440에서 **본문 폭 1320 · 좌우 60**, 375에서 **345 · 좌우 15**가 된다(PW 실측과 같음).

## 7. 사용자 확인이 필요한 디자인 결정

1. **기준 문서 차이** — `design-system.md`(v2, 액션 색 `#0066cc`·제목 600·알약 버튼)가 실제 `jc.css` v3(J블루 `#1E3AFF`)보다 오래됐다. 이 문서는 jc.css 색을 따랐고, 랜딩만의 예외 9개(1-5 표)를 표시했다. 예외를 `design-system.md`에 「랜딩 한정」으로 올릴지 정해 줘.
2. **제목·숫자 글꼴을 Pretendard 하나로** — 사이트 다른 화면의 제목(Wanted Sans)·큰 숫자(Archivo)와 이 랜딩만 달라진다. 히어로 보드 숫자도 Archivo 좁은 숫자 대신 Pretendard 880이 된다.
3. **03 분석 도구 바탕을 검정에서 흰색으로** — PW처럼 흰 바탕에 큰 화면 목업 2장을 두고, 순위 확인 폼은 그 아래 검정 띠로 옮긴다.
4. **히어로 배경에 홈과 같은 `hero-bg.webp`(파란 곡선)를 다시 쓴다** — 홈 첫 화면과 같은 그림이 반복된다. 싫으면 순수 검정 바탕 + I1만으로 간다.
5. **실측보다 키운 작은 글씨 세 곳** — 고지·캡션 11→12px, 375 표 머리(dt) 10→11px, 링크 칩 12→13px. 보장 안 함 같은 고지가 읽히게 하려는 것이다. PW 값 그대로 원하면 되돌린다.
6. **히어로 보드의 빨간 ▲ 표시를 뺀다** — jc.css 규칙상 빨강은 순위 상승 표시에만 쓰는데, 보드 숫자(30초·0원·1,200+)는 순위 상승이 아니다.
7. **목업 속 순위는 상승을 보여 주지 않는다** — 히어로 12위, 기록 그래프 14위 안팎의 평평한 선(「기준선」)만 그렸다. 진행 전후 변화를 보여 주는 그림은 실제 고객 기록이 들어오기 전에는 넣지 않는 것을 권한다.
8. **미션 화면은 특정 앱 화면이 아닌 「리워드 앱 미션 예시」로 그린다** — 꼬꼬농장·당근캐시의 실제 미션 화면 캡처가 있으면 그걸로 바꾸는 편이 더 정확하다(그 경우 캡처 제공이 필요).
9. **매체 띠 앱 아이콘 56→88px(375 60px)** — 공용 부분 파일은 그대로 두고 랜딩 안에서만 키운다.
