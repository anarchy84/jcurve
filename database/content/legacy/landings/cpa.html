CPA 포트폴리오

주요 운영 광고 상품

페이스북 파트너 등록, 구글 전담 담당자 지정 받은 광고대행사입니다. 이외 각 광고매체사 공식 제휴를 통한 철저한 마케팅 지원을 받고 있습니다.

랜딩/어드민 시스템 및 소재 제작

자체 개발 한 어드민 시스템을 제공합니다.

어드민 시스템
운영자, 광고주, 마케터, 상담원으로 이어지는 CPA 어드민 시스템을 제공합니다. 캠페인, 랜딩페이지, 입력양식, API 연동, 마케터/광고방식에 따른 개별 URL 생성, URL별 데이터 분석이 가능합니다.
랜딩페이지 제작
시스템 내부에 다양한 랜딩페이지 레이아웃이 준비되어 있습니다. 랜딩페이지 생성 메뉴에서 이미지와 텍스트만 업로드하면 자동으로 랜딩페이지가 생성됩니다. 원하는 디자인 구현 가능합니다.
입력양식
캠페인별 원하는 입력양식 생성가능. 예) 핸드폰(이름, 연락처, 현재통신사, 희망기종), 결혼정보회사 입력양식(이름, 연락처, 여성, 서울/경기, 나이, 학력, 직업)
API 연동
광고주가 본인 어드민 시스템에 DB 입력 받기 원하는 경우. 광고주가 본인들 랜딩페이지를 고집하는 경우. API 설정을 통해 수집 한 DB를 전송 할 수 있습니다.
개별 URL 생성
마케터/광고방식에 따른 개별 URL 생성이 가능. URL별로 수집 한 DB의 분석이 가능합니다. 광고주는 본인에게 연결된 캠페인의 DB만 확인 가능. 마케터는 본인 URL로 수집한 DB만 확인 가능.
회원 관리
운영자는 광고주, 마케터, 상담원 아이디를 생성/관리 할 수 있습니다. 생성된 캠페인에 광고주, 마케터, 상담원을 등록하면 본인들이 등록된 캠페인의 DB만 확인 가능합니다.

CPA(Cost Per Action) 마케팅?

목표 타겟(Target)이 광고주가 원하는 행동을 할 때만 광고비를 지급하는 마케팅 방식.

  1. 1

    목표 타겟

    성별, 연령, 지역, 직업, 소득, 신용상태 등 지정 가능

  2. 2

    광고주가 원하는 행동?

    회원가입, 설문지 작성, 앱설치, 개인정보 입력 등

  3. 3

    횟수 지정 가능

    100건 단위 계약 후 진행 가능

CPA 마케팅 형태

광고주가 제공하고자 하는 제품/서비스에 대한 관심이 있는 잠재고객의 개인정보를 수집

상품 및 서비스 홍보
광고주가 제공하고자 하는 제품/서비스에 대한 관심이 있는 잠재고객에게 광고를 통해 홍보
자발적인 개인정보 기입

아웃바운드 콜을 통한 판매
콜직원 또는 콜조직을 통해 판매/방문유도/매출증대 등의 목적을 달성
