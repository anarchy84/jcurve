AI 답변의 출처가 되려면 먼저 AI가 페이지를 읽을 수 있어야 합니다. 사람 눈에는 잘 보이는 페이지라도 상세 설명이 통이미지이거나, 화면과 코드의 정보가 다르면 AI는 핵심 내용을 놓치거나 잘못 이해합니다. 사이트를 새로 만들지 않고 운영 중인 페이지에서 시작하는 GEO 콘텐츠 정비 방법을 정리합니다.

사람이 보는 화면과 AI가 읽는 정보는 왜 다른가요?

AI와 검색엔진은 페이지를 글자 데이터로 이해합니다. 그래서 다음과 같은 경우 사람이 보는 내용과 AI가 읽는 내용이 달라집니다.

  • 이미지 속 글자 — 상세 설명·가격표·사양을 이미지로만 올리면 AI가 읽을 글자가 없습니다.
  • 화면과 코드의 불일치 — 화면 가격과 구조화 데이터의 가격이 다르면 AI는 코드 쪽을 근거로 삼기 쉽습니다.
  • 비어 있는 설명 — 구조화 데이터의 설명 칸이나 이미지 대체 텍스트가 비어 있습니다.
  • 페이지와 맞지 않는 메타 설명 — 모든 페이지에 회사 소개 한 줄이 똑같이 들어가 있습니다.

먼저 진단합니다 — 세 가지 질문

  1. 접근할 수 있는가 — robots.txt에서 AI 크롤러를 막고 있지 않은지, 방화벽이나 접속 대기열이 크롤러를 돌려보내지 않는지 확인합니다.
  2. 실제 내용을 읽을 수 있는가 — 핵심 정보가 처음 받는 HTML 안에 글자로 들어 있는지 봅니다. 화면을 그린 뒤에야 내용이 채워지는 구조라면 읽히지 않을 수 있습니다.
  3. 올바르게 이해할 수 있는가 — 대표 URL(canonical), 색인 상태, 메타 정보, 구조화 데이터가 화면과 맞는지 점검합니다.

진단 결과는 개발팀이 고칠 기술 보완 과제와, 글을 더할 콘텐츠 보강 과제로 나눠 정리합니다.

이미 가진 자산에서 정보를 꺼냅니다

상세 이미지를 만드는 데 들인 노력을 AI가 읽는 정보로 옮기는 것이 첫 단계입니다.

  1. 수집 — 상품·서비스 데이터, 상세 설명, 상세 이미지, 후기
  2. 추출 — 이미지 속 문구와 특징을 글자로 꺼냅니다.
  3. 구분 — 판매자가 적은 문구, 사진에서 보이는 외형, 분위기 같은 해석, 확인할 수 없는 항목을 나눠 담습니다.
  4. 작성·검토 — 원문과 대조해 통과한 내용만 페이지에 반영합니다.

근거의 성격을 나눠 두면 사실과 해석이 섞이지 않습니다. 예를 들어 상세 이미지에 "울 블렌드"라고 적혀 있다면 그대로 쓰고, 보온 수치처럼 원천에 없는 정보는 만들지 않고 "확인 불가"로 남깁니다. 후기는 한 건의 인상이 아니라 어떤 조건의 구매자가 어떤 경험을 했는지로 종합하고, 작성자를 알아볼 수 있는 정보는 넣지 않습니다.

항목목적위치
메타 설명그 페이지가 답하는 내용을 간결하게 요약코드
이미지 대체 텍스트이미지에 담긴 특징을 글로 설명코드

요약·Q&A 블록은 접어서 보여 줘도 HTML 안에 글자로 들어 있으면 읽힙니다. 네 가지가 서로 다른 효능이나 조건을 말하지 않도록 사실과 표현 수준을 맞추는 것이 핵심입니다.

원문과 대조해 거르는 문장

  • 원문에 없는 효과·특징을 덧붙인 문장 → 삭제
  • 원문과 달라진 숫자·단위 → 원문 값으로 수정
  • 확인되지 않는 인증·특허·수상 표현 → 삭제
  • "최고", "유일" 같은 근거 없는 단정 → 삭제하거나 근거가 있는 표현으로

건강기능식품·의료처럼 표현 기준이 엄격한 업종은 담당자의 최종 검토를 거칩니다.

업종마다 AI가 찾는 정보가 다릅니다

  • 매장(플레이스) — 위치, 영업 정보, 메뉴와 가격, 예약·주차
  • 쇼핑몰 상품 — 소재, 사이즈와 핏, 사용 상황, 관리 방법
  • 식품 — 원재료, 알레르기 성분, 보관·조리 방법
  • B2B 서비스 — 제공 범위, 진행 절차, 비용이 정해지는 기준, 사례의 출처

자주 묻는 질문

상세 설명이 이미지로만 되어 있으면 AI가 못 읽나요?

이미지 속 글자는 글자 정보로 따로 들어 있지 않으면 읽기 어렵습니다. 이미지 속 문구와 특징을 꺼내 본문 글, 대체 텍스트, 요약 블록으로 옮겨 두는 것이 좋습니다.

GEO를 하려면 사이트를 새로 만들어야 하나요?

아닙니다. 운영 중인 페이지에 메타 설명, 이미지 대체 텍스트, 구조화 데이터, 요약·Q&A 블록을 더하는 방식으로 시작합니다.

AI가 읽기 좋게 내용을 더 그럴듯하게 써도 되나요?

안 됩니다. 원본 페이지와 자료에서 확인되는 사실만 쓰고, 원문에 없는 효과나 달라진 숫자, 확인되지 않는 인증 표현은 걸러 냅니다. 확인할 수 없는 항목은 만들지 않습니다.

반영한 뒤에는 같은 질문으로 다시 봅니다

반영한 날짜를 기준점으로 두고, 적용 전에 고정한 질문으로 AI 답변을 다시 측정합니다. 언급보다 우리 페이지가 출처로 인용되는지를 중심으로 보고, 밀리는 질문에서 비어 있는 정보를 다시 보강합니다. 측정 지표와 계산 기준은 GEO 성과 측정 방법에서, 제이커브의 GEO 진행 방식은 GEO 생성엔진 최적화 페이지에서 볼 수 있습니다.
