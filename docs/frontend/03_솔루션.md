## 전략 요약 — "우리는 도구까지 직접 만든다"

제이커브의 최대 차별점(PLAN 차별점)은 **자체 솔루션 4종 보유**다. 대행만 하는 게 아니라
현장에서 필요한 소프트웨어를 직접 개발·운영한다. 4종이 두 축으로 갈린다:

| 축 | 솔루션 | 대상 | 실서비스 도메인 |
|---|---|---|---|
| **마케팅 데이터** | 랭크프리 | 네이버 마케팅하는 사장님·셀러 | rankfree.kr |
| | 부스팅샵 | 셀프 마케팅 원하는 사업자 | (사이트 내) |
| **보험 세일즈 CRM** | 리드베이 | 보험DB 사는 쪽(영업조직) | leadbay.co.kr |
| | 콜투세일 | 보험DB 파는 쪽(콜센터) | call2.sale |

> ⭐ 리드베이·콜투세일은 **보험DB 시장의 양면을 각각** 잡는다(수요·공급). 이 대칭 자체가 스토리다.

## 라우트 신설 필요 ⚠️ (클로드코드)

현재 web.php에는 `solutions.rankfree`, `solutions.boostingshop`만 있다. 아래 추가 필요:
```php
Route::get('/solutions', [PageController::class,'solutions'])->name('solutions.index');   // 허브
Route::get('/solutions/leadbay',   [PageController::class,'leadbay'])->name('solutions.leadbay');
Route::get('/solutions/call2sale', [PageController::class,'call2sale'])->name('solutions.call2sale');
```
- 리드베이·콜투세일은 **별도 도메인에서 실서비스가 운영 중** → 제이커브 사이트엔 "소개 랜딩"만 두고
  실제 서비스는 외부 도메인으로 `target="_blank" rel="noopener"` 연결.
- 내비 '솔루션' 드롭다운에 4개 다 노출(마스터 2장 내비 표 업데이트).

## 1. 랭크프리 (RankFree) — `/solutions/rankfree`

**실서비스**: rankfree.kr · 무료 순위분석 SaaS. **[검증됨] 실사이트 메타 기반 카피.**

### 히어로 [파치먼트]
```
라벨:  RANKFREE
H1:    네이버 마케팅, 순위부터 시장까지 한눈에
리드:  키워드만 넣으면 플레이스·쇼핑 순위, 경쟁사, 시장 규모까지.
       가입 없이 30초, 대부분 무료입니다.
CTA:   [무료로 시작]  → rankfree.kr/register (외부, 새 탭)
증거:  이미 1,200+ 사장님이 순위를 확인했습니다.   {{-- 실사이트 확정 수치 --}}
```

### ① 문제 [라이트]
```
소제목:  "순위가 왜 떨어졌는지, 아무도 안 알려준다."
본문:    순위 체크만 해주는 툴은 많습니다. 정작 '왜 떨어졌나'는 답이 없죠.
         리뷰가 부족한지, 저장수가 밀리는지, 어떤 키워드에서 빠지는지 —
         그 근거가 있어야 개선을 합니다.
```

### ② 방법 [다크] — 4개 분석 축
```
소제목:  순위 확인만? 분석까지 한 번에.
포인트:
  · 플레이스 — 순위 추적 + 상위 30위 경쟁사 비교 + SEO 점수 진단(N1·N2·N3)
  · 쇼핑 — 순위추적 + 6개월 시장 규모·매출 추정 + 셀러력·리뷰 분석
  · 키워드 — 검색량·트렌드 + 기회점수로 '황금 키워드' 발굴 + 엑셀 대량분석
  · 블로그 — 검색 상위 블로거 수집·지수화(체험단 섭외 전 영향력 판단)
  · 순위 API — 키 발급으로 순위 데이터를 내 서비스에 연동
```

### ③ 증거·요금 [파치먼트]
```
요금(실서비스 확정):
  · 무료 — 순위체크 100개 / 플레이스·경쟁분석 월 5회 / 키워드·블로그·쇼핑 분석
  · 프로 29,000원/월 — 순위체크 무제한 + 자동추적·알림 + 순위 API
  · 마케팅 대행 — 맞춤 견적 (분석 + 실행까지)

⚠️ 필수 고지(실사이트 명시): "순위·점수(N1·N2·N3)는 자체 수집·분석 기반 추정치이며
   네이버 공식 지표가 아닙니다." → 이 문구를 페이지에 반드시 노출. [Evidence Guardian]
```

### ④ 연결 [라이트]
```
· 분석에서 끝나지 않습니다 — 플레이스 최적화 / 블로그·체험단 / 광고 대행으로 연결
  (→ 제이커브 /services/seo, /services/performance-marketing 와 상호 링크)
CTA: [무료로 시작]  → rankfree.kr/register
```

## 2. 부스팅샵 (BoostingShop) — `/solutions/boostingshop`

**성격**: 셀프 마케팅 솔루션. 기존 사이트 '숍'(백링크 패키지·인스타 지표) 승계(URL-MIGRATION).

### 히어로 [파치먼트]
```
라벨:  BOOSTINGSHOP
H1:    직접 돌리는 셀프 마케팅
리드:  대행을 맡길 예산이 부담이라면, 필요한 마케팅을 직접 골라
       바로 실행하세요. 패키지로 간단하게.
CTA:   [상품 보기]  → 하위(basic/pro/elite)
```

### ① 문제 [라이트]
```
소제목:  "대행은 비싸고, 혼자 하긴 막막하다."
본문:    소상공인에게 풀 대행은 부담입니다. 그렇다고 뭘 어떻게 해야 할지
         막막하죠. 검증된 셀프 마케팅 상품을 골라 바로 시작할 수 있게 했습니다.
```

### ② 방법·상품 [다크]
```
소제목:  필요한 것만, 패키지로
하위 상품(URL-MIGRATION §C):
  · SEO 캠페인 베이직 → /solutions/boostingshop/basic
  · SEO 캠페인 프로   → /solutions/boostingshop/pro
  · SEO 캠페인 엘리트 → /solutions/boostingshop/elite
  · 인스타 인기게시물  → /solutions/boostingshop/instagram-popular
  · 인스타 팔로워     → /solutions/boostingshop/instagram-followers
  · 인스타 좋아요     → /solutions/boostingshop/instagram-likes
```
> ⚠️ [검증] 인스타 팔로워/좋아요/인기게시물 상품은 **플랫폼 정책·표시광고 리스크**가 있다.
> "어뷰징/가짜 지표" 오해를 살 표현 주의. 카피는 대웅 확인 후. 우선 상품명+가격만.
> 백링크 패키지는 기존 "월 50만원~"(CONTENT.md) 승계.

### ⑥ CTA [다크]
```
H:   예산에 맞게, 필요한 것부터
CTA: [상품 보기]
```

## 3. 리드베이 (LEADBAY) — `/solutions/leadbay`

**실서비스**: leadbay.co.kr · 보험 영업조직용 세일즈 CRM. **[검증됨] 실사이트 메타 기반.**
**⚠️ 규제 민감(보험DB·개인정보)** — 실서비스 표현을 그대로 승계, 지어내지 않는다.

### 히어로 [파치먼트]
```
라벨:  LEADBAY
H1:    보험DB 구매부터 계약 관리까지, 한 흐름으로
리드:  검증된 보험DB 업체를 품질 점수·납품 속도·AS 정책으로 비교해 구매하고,
       상담·계약·AS·정산까지 한 곳에서 관리하는 보험 영업 CRM.
CTA:   [리드베이 바로가기]  → leadbay.co.kr (외부, 새 탭)
```

### ② 방법 [다크]
```
소제목:  DB를 사는 순간부터 계약까지, 새는 곳 없이
포인트:
  · 보험DB 마켓 — 검증된 업체를 품질점수·납품속도·AS로 비교 구매
  · 상담 관리 — 구입한 DB의 상담 배분·진행 상태 추적
  · 계약·AS·정산 — 계약 체결부터 사후 관리까지 한 흐름
대상:  보험 영업조직 / 설계사 / 대리점 (DB를 '사는' 쪽)
```

### 연결
```
· 보험 CPA 마케팅과 연결 → /services/cpa-marketing/insurance
  (보험 영업조직이 DB 유입~관리까지 원스톱)
CTA: [리드베이 바로가기]  → leadbay.co.kr
```
> ⚠️ [Client Risk] "보험DB 구매"는 개인정보·표시광고 규제 영역. **실서비스 문구만 승계**하고
> "수익/실적 보장" 류 표현 금지. 카피 최종 확정은 대웅.
